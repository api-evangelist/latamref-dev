Latamref provides Latin American government reference data, offering every value cited to its official source with effective and last‑verified dates. The service includes endpoints for countries, accuracy metrics, status, and pricing, and supplies documentation and quickstart guides for developers. It aims to deliver reliable, up‑to‑date public sector information via a simple API.

**Areas:** Data · Government · LatinAmerica · API · Reference

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Latamref: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
